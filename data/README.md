# Данные

- `raw/` — неизменяемые исходные обезличенные выгрузки (не добавлять чувствительные данные).
- `synthetic/` — сценарии и генераторы учебных данных.
- `processed/` — производные наборы; должны быть воспроизводимы из исходных данных.
- `schemas/` — схема полей и единицы измерения.

Для каждого набора обязателен файл происхождения: источник, дата, трансформации, версия и seed (если применимо).
