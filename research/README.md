# Исследования

Здесь хранится доказательная база проекта, а не поток заметок.

## Структура

- `questions.md` — открытые исследовательские вопросы.
- `sources/` — карточки источников в формате Markdown.
- `hypotheses/` — проверяемые гипотезы об улучшении процесса.
- `notes/` — краткие рабочие конспекты с обязательной ссылкой на источник.

## Шаблон карточки источника

```markdown
# Название

- Тип: статья / стандарт / документация / отчёт
- Автор или организация:
- Год:
- URL или DOI:
- Дата обращения:
- Надёжность и ограничения:

## Что подтверждает

- Тезис:
- Цитата или точная опора в источнике:
- Как это применяется в проекте:
```
