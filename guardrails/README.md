# Guardrails

Эти правила обязательны для пользователей и AI-агентов.

## Качество исследования

- Не выдавать предположения за факты.
- У каждого внешнего источника фиксировать автора/организацию, дату, URL/DOI, дату обращения и краткую цитату или тезис.
- У каждого синтетического набора данных фиксировать генератор, параметры, seed и ограничения применимости.
- Не использовать непроверенные цифры экономического эффекта.

## Данные и этика

- Не помещать в репозиторий персональные данные, производственные логи, учётные данные, токены или закрытую документацию.
- Для реальных данных хранить только согласованный обезличенный экспорт и описание доступа.
- Значимые входные файлы не переписывать без версии и журнала происхождения.

## Агентская разработка

- Агент сначала читает контекст фазы и связанные исследования; затем предлагает минимальное изменение.
- Агент не придумывает результаты запусков, тестов, моделирования и источников.
- Агент не меняет архитектуру, методику эксперимента или критерии эффективности без явной записи в `plans/decisions/`.
- Для кода: сначала тест/сценарий проверки, затем реализация, затем фактический запуск проверки.

## Стоп-условия

Остановиться и запросить решение наставника, если: предметная модель противоречива; источник нельзя проверить; данные содержат чувствительную информацию; изменение делает результаты несопоставимыми с предыдущими экспериментами.
