# Глоссарий

| Термин | Рабочее определение | Статус |
|---|---|---|
| ТОиР | Техническое обслуживание и ремонт оборудования. | Требует источника |
| Заявка | Единица работы, поступающая в процесс обработки ТОиР. | Учебное определение |
| SLA | Согласованный целевой уровень/срок обслуживания, используемый для оценки заявки. | Требует источника |
| AS-IS | Модель текущего состояния процесса. | Методологический термин |
| TO-BE | Модель целевого состояния процесса. | Методологический термин |
