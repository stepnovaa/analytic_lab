# Артефакты аналитика

- `business-process/` — BPMN AS-IS/TO-BE, карта ролей и событий.
- `requirements/` — функциональные, нефункциональные требования и критерии приёмки.
- `glossary.md` — согласованные термины.
- `adr/` — решения по моделированию и архитектуре.

Диаграммы должны храниться в редактируемом исходном формате и, при необходимости, в экспортном PDF/SVG.
