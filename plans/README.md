# Планы и фазы

- `roadmap.md` — последовательность фаз и критерии перехода.
- `phases/` — детальные рабочие планы по фазам.
- `decisions/` — короткие ADR: принятые решения, альтернативы, последствия.
- `iterations/` — цели, результаты и ретроспективы учебных итераций.

Каждая фаза должна иметь цель, входы, ожидаемые артефакты, критерии готовности и вопросы, которые нельзя закрывать предположениями.
